# projects

Projects

PharmUniverse Security Management Plan

[grc] ISO/IEC 27001:2022 · CVSS v3.1 · ALE / ROSI · Python

A 53-page ISMS plan for a fictional multinational pharmaceutical manufacturer. Five risks to two critical assets are scored with CVSS v3.1 and annualised loss expectancy; six Annex A controls cut expected annual loss from about £6.35m to £1.38m (78%), backed by cost-benefit and sensitivity analysis, a Statement of Applicability extract and a 15-month certification roadmap.

A Python model reproduces every risk, control and cost figure, so the numbers can be checked and re-run.

Fictional case study adapted from an ISACA caselet. It began as MSc coursework in 2023 and was redrafted in 2026 with AI assistance; the README explains how.
